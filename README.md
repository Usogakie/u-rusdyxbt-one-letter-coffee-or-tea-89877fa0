One letter, A for coffee. A tiny Python program that writes a single letter to `entry.txt` for make.fun's "One Letter: Coffee or Tea" bounty: A stands for coffee, the bolder, more vivid answer in the coffee against tea argument.

## Run it

```sh
python3 main.py
```

It writes exactly one character, `A` with no newline, to `${MAKEFUN_OUTPUT_DIR:-/output}/entry.txt`.
